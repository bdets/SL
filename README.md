# পড়ার খাতা — Study Ledger (Phase 1 ডেমো)

ছাত্র / টিউটর / অভিভাবক / প্রশাসক — ৪ স্তরের লগিন সহ পড়াশোনা তদারকি অ্যাপ।
এই ভার্সনে সব ডাটা আপনার ব্রাউজারের **localStorage**-এ (একই ডিভাইসে) সেভ থাকে,
যাতে পুরো ফিচার সেট (টাস্ক, রিভিশন লগ, মেসেজ, নোটিফিকেশন) ঝামেলা ছাড়া টেস্ট করতে পারেন।

## চালানোর নিয়ম

**⚠️ গুরুত্বপূর্ণ:** সরাসরি `index.html` ফাইলে ডাবল-ক্লিক করলে (file:// দিয়ে) PWA ইনস্টল/অফলাইন
ফিচার কাজ করবে না — ব্রাউজার নিরাপত্তার কারণে Service Worker file:// এ চলে না।
তাই একটা ছোট লোকাল সার্ভার দিয়ে খুলুন:

```bash
# এই ফোল্ডারের ভেতরে গিয়ে
python3 -m http.server 8080
# তারপর ব্রাউজারে খুলুন:
http://localhost:8080
```

অথবা VS Code-এর "Live Server" extension ব্যবহার করতে পারেন।

### মোবাইল/ল্যাপটপে ইনস্টল করে সত্যিকার ব্যবহারের জন্য
পরিবারের সবাই (স্টুডেন্ট, টিউটর, অভিভাবক) যেন যার যার ডিভাইস থেকে ব্যবহার করতে পারে,
এই ফোল্ডারটা যেকোনো ফ্রি স্ট্যাটিক হোস্টিং-এ আপলোড করুন (এতে স্বয়ংক্রিয়ভাবে HTTPS পাবেন,
যা PWA ইনস্টলের জন্য দরকার):
- **GitHub Pages** (বিনামূল্যে)
- **Netlify** / **Vercel** (drag & drop করলেই হোস্ট হয়ে যায়)

হোস্ট করার পর সেই লিংক মোবাইলে Chrome-এ খুলে "হোম স্ক্রিনে যোগ করুন" চাপলেই অ্যাপ হিসেবে ইনস্টল হয়ে যাবে।

## ডেমো লগিন (পাসওয়ার্ড সব জায়গায়: `1234`)

| রোল | ইউজারনেম | নাম |
|---|---|---|
| ছাত্র | `student` | আরিয়ান হোসেন |
| ছাত্র | `student2` | ফারিহা আক্তার |
| টিউটর | `tutor` | ইমরান হোসেন |
| অভিভাবক | `guardian` | সালমা বেগম |
| প্রশাসক | `admin` | রফিকুল ইসলাম |

লগিন স্ক্রিনে রোল বেছে নিয়ে নিচের "ডেমো অ্যাকাউন্ট" বাটনে চাপলেই দ্রুত ঢুকে যাবে।
একসাথে দুই ট্যাবে দুইটা ভিন্ন রোলে লগিন করে (যেমন এক ট্যাবে টিউটর, আরেক ট্যাবে স্টুডেন্ট)
টাস্ক দেওয়া, সম্পন্ন করা, মেসেজ চালাচালি — সব লাইভ দেখতে পারবেন (রিফ্রেশ দিলে আপডেট আসবে)।

## এখন যা কাজ করে (Phase 1)
- ৪ রোলের লগিন ও পৃথক ড্যাশবোর্ড
- টিউটরের পড়া/টাস্ক দেওয়া (বিষয়, অধ্যায়, পৃষ্ঠা, প্রশ্ন, ধরন, তারিখ)
- স্টুডেন্টের টাস্ক "সম্পন্ন / আংশিক" করা, নোট যোগ করা
- মেয়াদ পার হলে স্বয়ংক্রিয়ভাবে "মিস হয়েছে" দেখানো
- বিষয়ভিত্তিক রিভিশন লগ (পৃষ্ঠা + প্রশ্নসহ, সাপ্তাহিক/মাসিক/ত্রৈমাসিক/সব-সময় ফিল্টার) — পরীক্ষার আগে গোছানো রিভিশনের জন্য
- সিলেবাস ব্যবস্থাপনা (এডমিন) ও সিলেবাস-ভিত্তিক অগ্রগতি % (সবার ড্যাশবোর্ডে)
- সাপ্তাহিক রুটিন/ক্লাস-শিডিউল (টিউটর যোগ করেন, ছাত্র/অভিভাবক দেখেন)
- অভিভাবক/প্রশাসকের সার্বিক পর্যবেক্ষণ, পিছিয়ে পড়া স্টুডেন্ট চিহ্নিতকরণ
- প্রশাসকের ইউজার/টিউটর যোগ করা ও লিংক করা
- বার্তা আদান-প্রদান (স্টুডেন্ট ↔ টিউটর ↔ অভিভাবক ↔ প্রশাসক)
- ইন-অ্যাপ নোটিফিকেশন
- PWA ইনস্টল ও অফলাইন সাপোর্ট (Service Worker)
- **Phase 2: Firebase দিয়ে লাইভ multi-device সিঙ্ক** (নিচে দেখুন)

## ☁️ Phase 2 — লাইভ সিঙ্ক (Firebase) চালু হয়েছে

অ্যাপে এখন একটা Firebase প্রজেক্টের সাথে সংযোগ যুক্ত আছে (`firebase-sync.js`)। এর মানে —
- সব ডিভাইস (স্টুডেন্ট, টিউটর, অভিভাবক, এডমিন) একই ডাটা লাইভ শেয়ার করবে
- টপবারে ডানপাশে 🌐 (লাইভ সিঙ্ক চালু) বা 📴 (অফলাইন মোড, শুধু এই ডিভাইসে সেভ হচ্ছে) দেখাবে
- ইন্টারনেট না থাকলেও অ্যাপ চলবে (localStorage থেকে), নেট ফিরলে স্বয়ংক্রিয়ভাবে সিঙ্ক হয়ে যাবে

### ⚠️ জরুরি — এই দুইটা কাজ Firebase Console থেকে করে নিন

**১. Firestore Security Rules সেট করুন** (ডিফল্ট "টেস্ট মোড" মাত্র ৩০ দিন পর বন্ধ হয়ে যায়):
Firebase Console → Firestore Database → Rules ট্যাবে গিয়ে এই কোডটা বসান ও Publish করুন:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /sync/{document} {
      allow read, write: if request.auth != null;
    }
    match /photos/{document} {
      allow read, write: if request.auth != null;
    }
    // pk_users, pk_tasks, pk_messages, pk_notifications, pk_routine,
    // pk_followups, pk_payments — one small doc per record (see "ডাটার
    // স্কেল" সেকশন নিচে)
    match /pk_users/{document} { allow read, write: if request.auth != null; }
    match /pk_tasks/{document} { allow read, write: if request.auth != null; }
    match /pk_messages/{document} { allow read, write: if request.auth != null; }
    match /pk_notifications/{document} { allow read, write: if request.auth != null; }
    match /pk_routine/{document} { allow read, write: if request.auth != null; }
    match /pk_followups/{document} { allow read, write: if request.auth != null; }
    match /pk_payments/{document} { allow read, write: if request.auth != null; }
  }
}
```
⚠️ আপনার Firestore-এ যদি আগে থেকেই কোনো rules সেট করা থাকে, ওপরের পুরো ব্লকটা কপি-পেস্ট করে
পুরোনোটা replace করুন — শুধু নতুন লাইনগুলো যোগ করলে পুরোনো `match` ব্লক ডুপ্লিকেট হয়ে এরর দিতে পারে।

**২. যেখানে হোস্ট করবেন সেই ডোমেইন Authorized করুন**:
Firebase Console → Authentication → Settings → Authorized domains → "Add domain" —
এখানে আপনার Netlify/GitHub Pages ডোমেইনটা যোগ করুন (যেমন `porar-khata.netlify.app`)।
`localhost` এমনিতেই যুক্ত থাকে, তাই লোকাল টেস্টিং-এ এই ধাপ লাগবে না।

### কীভাবে টেস্ট করবেন যে সিঙ্ক আসলেই কাজ করছে
দুইটা ভিন্ন ব্রাউজার ট্যাব/উইন্ডো খুলুন (একটা normal, একটা Incognito) — একটায় `tutor` দিয়ে লগইন করুন, অন্যটায় `student` দিয়ে। টিউটর ট্যাব থেকে নতুন পড়া দিন — কয়েক সেকেন্ডের মধ্যে স্টুডেন্ট ট্যাবেও (রিফ্রেশ ছাড়াই) সেটা দেখা যাবে।

### ডাটার নিরাপত্তা সম্পর্কে
প্রথমবার অ্যাপ চালু হওয়ার সময় ক্লাউডে কোনো ডাটা না থাকলে একবারই ডেমো ডাটা তৈরি হয়ে ক্লাউডে জমা হয় —
এরপর থেকে সব ডিভাইস সেই একই শেয়ার্ড ডাটা ব্যবহার করবে, কেউ কারো ডাটা ওভাররাইট করবে না।
ডেমো ইউজারগুলো (student, tutor, guardian, admin ইত্যাদি) মুছে/পরিবর্তন করে আসল নাম-ইউজারনেম
দিয়ে বদলে নিতে চাইলে জানাবেন, সেটার জন্য এডমিন প্যানেলে এডিট/ডিলিট অপশন যোগ করে দেব।

## 📈 ডাটার স্কেল নিয়ে গুরুত্বপূর্ণ একটা আপডেট (~১২০০-১৫০০ স্টুডেন্ট স্কেলের জন্য)

আগের ভার্সনে প্রতিটা কালেকশন (সব ইউজার, সব টাস্ক, সব পেমেন্ট...) **একটাই** Firestore ডকুমেন্টে
পুরো JSON অ্যারে হিসেবে জমা থাকত। ১২০০-১৫০০ স্টুডেন্ট স্কেলে এটা বাস্তবেই ভেঙে পড়ত —
- Firestore-এ একটা ডকুমেন্টের সাইজ-লিমিট ১MB। এই স্কেলে "সব টাস্ক" বা "সব নোটিফিকেশন" এর
  ব্লব কয়েক সপ্তাহের মধ্যেই (বছর লাগত না) এই লিমিট ছুঁয়ে ফেলত — এরপর সিঙ্ক নীরবে ফেইল করা শুরু করত।
- প্রতিটা সেভেই পুরো অ্যারে আবার আপলোড হতো — দুইজন প্রায় একই সময়ে সেভ করলে একজনের
  পরিবর্তন আরেকজনের (সম্পূর্ণ অসম্পর্কিত) পরিবর্তনকে চাপা দিয়ে দিতে পারত (ডাটা হারানোর ঝুঁকি)।

**সমাধান করা হয়েছে**: এখন প্রতিটা রেকর্ড (একটা টাস্ক, একজন ইউজার, একটা পেমেন্ট...) নিজের
আলাদা, ছোট Firestore ডকুমেন্ট — পুরো কালেকশনের একটাই ব্লব না। ফলে:
- ডকুমেন্ট সাইজ চিরকাল ছোট থাকবে, স্টুডেন্ট সংখ্যা যতই বাড়ুক না কেন।
- দুইজন ভিন্ন রেকর্ড এডিট করলে একজন আরেকজনের ডাটা চাপা দিতে পারবে না।
- সেভ করার সময় শুধু পরিবর্তিত রেকর্ডগুলোই আপলোড হয় (পুরো কালেকশন না) — দ্রুত ও কম ডাটা খরচ।

আগের ফরম্যাটে যদি ইতিমধ্যে আসল ডাটা জমা থাকে, অ্যাপ প্রথমবার নতুন কোড দিয়ে চালু হলে
স্বয়ংক্রিয়ভাবে সেই পুরোনো ডাটা নতুন ফরম্যাটে কপি করে নেবে (একবারই, ব্যাকগ্রাউন্ডে) —
পুরোনো ডকুমেন্টগুলো মোছা হয় না, ব্যাকআপ হিসেবে থেকে যায়।

`pk_subjects` (শ্রেণি+বিষয়ের তালিকা) ছোট ও এডমিন-নিয়ন্ত্রিত বলে আগের মতোই একটা ডকুমেন্টে থাকছে —
স্টুডেন্ট সংখ্যার সাথে এটা বাড়ে না, তাই আলাদা করার দরকার নেই।

⚠️ **এই আপডেট দেওয়ার পর অবশ্যই ওপরের নতুন Firestore Security Rules যোগ করুন** —
নাহলে নতুন কালেকশনগুলোতে (pk_tasks, pk_users ইত্যাদি) লেখা "permission denied" এরর দেবে।

## নতুন সংযোজন (এই আপডেট — সব ইউজারের ড্যাশবোর্ডে ডিফল্ট সাপ্তাহিক ফিল্টার)
- স্টুডেন্টের নিজের ড্যাশবোর্ড ও অভিভাবকের "সন্তানেরা" পাতার "📚 শিক্ষকের দেওয়া পড়া" / "📅 পড়া আদায়ের শেষ তারিখ অনুযায়ী" ট্যাব দুটিতেও এখন টিউটর/এডমিন ড্যাশবোর্ডের মতোই সময়কাল ফিল্টার (সাপ্তাহিক ডিফল্ট / পাক্ষিক / মাসিক / তারিখ অনুসারে) যোগ হয়েছে — এখন সব রোলের ড্যাশবোর্ডেই একই প্যাটার্ন।
- **দ্রষ্টব্য:** এই ফিল্টার শুধু স্ক্রিনে একসাথে কতগুলো কার্ড/লাইন আঁকা হচ্ছে সেটা কমায় — localStorage-এ বা Firestore সিঙ্কে ডাটা কতটুকু থাকছে সেটা পাল্টায় না (কারণ পুরো ডাটাসেটই এখনও লোড/সিঙ্ক হয়)। প্রকৃত ক্যাশ/স্টোরেজ চাপ কমাতে চাইলে ডাটা আর্কাইভিং বা Firestore কোয়েরি-লেভেল ফিল্টারিং লাগবে (README-তে আলাদা নোট হিসেবে রাখা হলো)।

## নতুন সংযোজন (এই আপডেট — ড্যাশবোর্ডের পড়ার তালিকায় ফিল্টার)
- টিউটর ও এডমিন — দুজনের ড্যাশবোর্ডেই "সকল পড়া" ব্লকে এখন **শ্রেণি ও শিক্ষার্থী বেছে নেওয়ার সিলেক্ট** যোগ হয়েছে (এডমিনের জন্য পুরো সিস্টেমের সব শ্রেণি/শিক্ষার্থী থেকে; টিউটরের জন্য নিজের শিক্ষার্থীদের মধ্যে থেকে) — তালিকাটা সেই অনুযায়ী সংকুচিত হবে।
- সময়কাল ফিল্টারে এখন **সাপ্তাহিক (ডিফল্ট, গত ৭ দিন) / পাক্ষিক (গত ১৫ দিন) / মাসিক (গত ৩০ দিন) / তারিখ অনুসারে** — এই ৪টা অপশন আছে।

## নতুন সংযোজন (এই আপডেট — টিউটর/এডমিন ড্যাশবোর্ডে পড়ার তালিকা)
- **টিউটরের ও এডমিনের ড্যাশবোর্ডে (নিচের দিকে)** এখন স্টুডেন্ট ড্যাশবোর্ডের মতোই "📚 শিক্ষকের দেওয়া পড়া" / "📅 পড়া আদায়ের শেষ তারিখ অনুযায়ী" — এই দুটো ট্যাব যোগ হয়েছে ("সকল পড়া" শিরোনামে)।
- প্রতিটা পড়ার লাইনে ক্লিক করলে এখন টিউটরের দরকারি বাটনগুলো (✏️ এডিট, 🗑️ মুছুন, আর সম্পন্ন পড়ার জন্য "সম্পন্ন হয়নি" ও "🔔 মনে করিয়ে দিন") খুলে আসবে — টিউটর ও এডমিন দুজনের ড্যাশবোর্ডেই একই এক্সেস।
- এডমিনের এই তালিকাটা ডিফল্টভাবে "সাপ্তাহিক" (গত ৭ দিন) সীমায় রাখা হয়েছে, সাথে মাসিক/তারিখ অনুসারে ফিল্টার — কারণ ১২০০-১৫০০ স্টুডেন্ট স্কেলে সবার সব পড়া একসাথে দেখানো আগে ইচ্ছাকৃতভাবে সরানো হয়েছিল (দেখুন নিচের পুরনো নোট) — এই ফিল্টার সেই সমস্যা এড়িয়ে একই সুবিধা দেয়।

## নতুন সংযোজন (এই আপডেট — বাগ ফিক্স ও ফিচার)
- **🐛 সাইলেন্ট সিঙ্ক-ফেইল ফিক্স**: আগে কোনো টাস্ক/আপডেট Firestore-এ পুশ করতে ব্যর্থ হলে (যেমন Security Rules মেয়াদ শেষ হয়ে যাওয়া, ডোমেইন Authorize না থাকা, বা নেট সমস্যা) সেটা শুধু ব্রাউজার কনসোলে লুকিয়ে থাকত — টপবারের 🌐 আইকন তখনও "লাইভ সিঙ্ক চালু" দেখাত, তাই টিউটর/এডমিন কখনো বুঝতেই পারতেন না যে দেওয়া পড়া আসলে অন্য কারো কাছে পৌঁছায়নি। এখন এমন কিছু ঘটলে আইকন ⚠️ দেখাবে এবং একটা সতর্কবার্তা (toast) আসবে।
- **স্টুডেন্ট ড্যাশবোর্ডের পুরনো "📘 আজকের পড়া" আলাদা মেনু-আইটেম সরানো হয়েছে** — এই একই তথ্য এখন ড্যাশবোর্ডের ভেতরেই "📚 শিক্ষকের দেওয়া পড়া" / "📅 পড়া আদায়ের শেষ তারিখ অনুযায়ী" ট্যাব দুটোতে আছে।
- **অভিভাবকের আইডিতেও** এখন সন্তানদের পাতায় "📚 শিক্ষকের দেওয়া পড়া" ও "📅 পড়া আদায়ের শেষ তারিখ অনুযায়ী" — এই দুটো ট্যাব যোগ হয়েছে (আগে স্টুডেন্টের আইডিতে শুধু ছিল)।
- **টিউটরের "আমার স্টুডেন্ট" → "পড়া/টাস্ক ফিল্টার"** এখন "❌ মিস হওয়া পড়া" ও "✅ সম্পন্ন হওয়া পড়া" — দুটো আলাদা ট্যাবে ভাগ হয়েছে, প্রতিটাতে সাপ্তাহিক/মাসিক/তারিখ অনুসারে (from–to) ফিল্টার সিলেক্ট যোগ হয়েছে।

## নতুন সংযোজন (সর্বশেষ আপডেট)
- **অভিভাবক ও টিউটরের পড়ার তালিকা**: এখন ছাত্রের মতোই তারিখ-ভিত্তিক গ্রুপ করা (বাকি/মিস হওয়া ও সম্পন্ন — আলাদা সেকশনে)
- **রিভিশন লগে "সম্পন্ন হয়নি" বাটন**: অভিভাবক/টিউটর মনে করলে কোনো পড়া ঠিকমতো আদায় হয়নি, এক ক্লিকে আবার "বাকি" করে দিতে পারবেন — স্টুডেন্ট নোটিফিকেশন পাবে
- **🔔 রিভিশন রিমাইন্ডার বাটন**: রিভিশন লগ থেকে নির্দিষ্ট কোনো পড়ার জন্য ছাত্রকে মনে করিয়ে দেওয়ার নোটিফিকেশন পাঠানো যাবে
- **টিউটরও এখন রিভিশন লগ দেখতে পারবেন** — নিজের স্টুডেন্ট বেছে নিয়ে
- **রুটিন**: সব প্রোফাইলে একই রকম টেবিল-ভিউ (দিন+সময় একই হলে এক সারিতে); এন্ট্রি করার সময় দিন ও সময় ফিল্ড পরের এন্ট্রিতে আগেরটাই থেকে যায় (শুধু বিষয়/নোট খালি হয়) — একই দিনে একাধিক ক্লাস যোগ করা সহজ
- **সিলেবাস এন্ট্রি**: শ্রেণি ও বিষয় পরের এন্ট্রিতে আগেরটাই থেকে যায়, শুধু টপিকের নাম খালি হয়
- **পড়া/টাস্ক এন্ট্রি**: টার্গেট (স্টুডেন্ট/শ্রেণি), স্টুডেন্ট বা শ্রেণি, দেওয়ার তারিখ, শেষ তারিখ — এসব পরের এন্ট্রিতে আগেরটাই থেকে যায়; "পৃষ্ঠা শুরু/শেষ" আলাদা ফিল্ড বাদ দেওয়া হয়েছে (এখন "অধ্যায়/টপিক" ফিল্ডেই পৃষ্ঠা-প্রশ্ন নম্বর লেখার নির্দেশনা দেওয়া যায়)

## নতুন সংযোজন (এর আগের আপডেটে)
- **এডমিন ড্যাশবোর্ড**: "সকল টাস্ক" তালিকা সরানো হয়েছে (এত ডাটা এডমিনের দরকার নেই); বদলে এখন **গত ৬ মাসের মাসিক আদায়ের হার চার্ট** দেখাবে
- **স্টুডেন্টের ড্যাশবোর্ড নতুন কার্ড**: "🗓️ আগামী ক্লাস" (রুটিন থেকে স্বয়ংক্রিয়ভাবে বের করা), "🔁 রিভিশন-চেক" (সাম্প্রতিক সম্পন্ন পড়ার ঝলক + রিভিশন লগের লিংক)
- **তারিখ-ভিত্তিক গ্রুপিং**: ড্যাশবোর্ড ও "আজকের পড়া" পেজে এখন কাজ "আজ"/"গতকাল"/"আগামীকাল" ইত্যাদি লেবেলে গ্রুপ করা — বাকি/মিস হওয়া পড়া ও সম্পন্ন পড়া আলাদা সেকশনে, প্রতিটা তারিখ-গ্রুপ আলাদা হেডিং সহ
- রিভিশন লগ (বিষয়+অধ্যায়ভিত্তিক সাজানো, পরীক্ষার প্রস্তুতির জন্য) আগের মতোই আলাদা মডিউল হিসেবে থেকে গেছে, যাতে "আজকের পড়া" পেজ পরিষ্কার থাকে

## নতুন সংযোজন (এর আগের আপডেটে)
- **বিষয়/সাবজেক্ট ম্যানেজমেন্ট**: "সিলেবাস" পেজে এখন নতুন বিষয় যোগ/মুছা যায় (টিউটর ও এডমিন দুজনেই)
- **ব্রডকাস্ট মেসেজিং**: এডমিন সব ছাত্র/সব টিউটর/সব অভিভাবক/সবাইকে একসাথে বার্তা পাঠাতে পারবেন; টিউটর নিজের সব স্টুডেন্ট/অভিভাবক/সবাইকে
- **সেটিংস মডিউল (এডমিন)**: ব্যাকআপ ডাউনলোড ও রিস্টোর আবার যোগ হয়েছে, এখন আলাদা "⚙️ সেটিংস" মেনুতে গোছানো
- **রিভিশন লিস্ট**: প্রতিটা বিষয়ের ভেতরে এখন অধ্যায়/চ্যাপ্টার অনুযায়ী সাজানো (সহজ ইনডেক্সের মতো)
- **নির্দিষ্ট তারিখ পর্যন্ত অবস্থা দেখা**: রিভিশন লগে একটা তারিখ বেছে নিলে সেই তারিখ পর্যন্ত কী কী সম্পন্ন ছিল আর কী বাকি ছিল দেখা যায়
- **ড্যাশবোর্ডে অগ্রাধিকার তালিকা**: স্টুডেন্টের ড্যাশবোর্ডে এখন মিস হওয়া ও বাকি থাকা পড়া শেষ-তারিখ অনুযায়ী সাজানো দেখায় (পুরনো/জরুরি আগে)
- **অভিভাবকের এক্সট্রা টাস্ক**: টিউটরের বাইরেও অভিভাবক নিজে সন্তানের জন্য অতিরিক্ত পড়া/কাজ যোগ করতে পারবেন (তালিকায় "অভিভাবক প্রদত্ত" ব্যাজসহ দেখাবে)
- **UI উন্নতি**: টাস্ক/পড়ার লেখা এখন গাঢ় ও বড় (আগে বেশি হালকা মনে হচ্ছিল); প্রতিটা টাস্ক এখন ক্লিক করলে খোলে এমন কম্প্যাক্ট লিস্ট (আগে সবসময় পুরো তথ্য দেখিয়ে অনেক জায়গা নিচ্ছিল); টিউটরের "নতুন যোগ করুন" ফর্মগুলো এখন ভাঁজ করা (ক্লিক করে খুলতে হয়), স্ক্রিন কম জটলা মনে হবে

## নতুন সংযোজন (এর আগের আপডেটে)
- **বাগ ফিক্স**: সব "বাতিল" ও "রিসেট" বাটন ঠিক করা হয়েছে (আগে একটা সাধারণ বাগের কারণে এগুলো কাজ করছিল না)
- **ব্যাকআপ/রিস্টোর সরানো হয়েছে**: এটা ঠিকমতো কাজ করছিল না এবং ইউজারের হাতে না রাখাই নিরাপদ, তাই সরিয়ে দেওয়া হয়েছে
- **বার্তা মডিউল**: এখন সবসময় স্বাভাবিক উলম্ব (vertical) লিস্ট, রোল (ছাত্র/টিউটর/অভিভাবক) অনুযায়ী ফিল্টার করা যায়
- **শ্রেণিভিত্তিক স্টুডেন্ট সিলেক্টর**: পড়া দেওয়ার ফর্ম, রুটিন, পেমেন্ট — সব জায়গায় স্টুডেন্ট এখন শ্রেণি অনুযায়ী গ্রুপ করা দেখায়
- **ইউজার ব্যবস্থাপনায় রোল-ফিল্টার**: এডমিন প্যানেলে রোল বেছে সেই রোলের ইউজার আলাদা করে দেখা যায়
- **পাসওয়ার্ড নিরাপত্তা**: এডিট করার সময় পাসওয়ার্ড আর প্লেইন টেক্সটে দেখা যায় না (হাইড থাকে); এডমিন/টিউটর চাইলে "ডিফল্ট পাসওয়ার্ডে রিসেট" করতে পারবেন
- **ডিফল্ট আইডি/পাসওয়ার্ড স্কিম**: টিউটর/অভিভাবক/এডমিনের জন্য ডিফল্ট ইউজারনেম ও পাসওয়ার্ড তাদের মোবাইল নম্বর; স্টুডেন্টের জন্য ডাকনাম (ইউজারনেম) ও শ্রেণি (পাসওয়ার্ড) — টাইপ করলেই স্বয়ংক্রিয়ভাবে ফিল্ড দুটো ভরে যায়, চাইলে বদলানো যায়
- **প্রোফাইল পেজ**: প্রত্যেক ইউজার (👤 প্রোফাইল মেনু থেকে) নিজের পাসওয়ার্ড নিজে পরিবর্তন করতে পারবেন

## নতুন সংযোজন (এর আগের আপডেটে)
- **শ্রেণিভিত্তিক ব্যবস্থাপনা**: টিউটর নিজের স্টুডেন্ট (এড/এডিট/রিমুভ), সিলেবাস (শ্রেণি+বিষয়ভিত্তিক), রুটিন — সবকিছু নিজে পূর্ণাঙ্গ CRUD দিয়ে ম্যানেজ করতে পারবেন
- **শ্রেণিভিত্তিক পড়া দেওয়া**: একজন স্টুডেন্ট বা পুরো শ্রেণিকে একসাথে পড়া দেওয়া যাবে; টাস্ক এডিট/মুছাও যাবে
- **অভিভাবকের একাধিক সন্তান লিংক**: এডমিন প্যানেলে অভিভাবক তৈরি/এডিট করার সময় একাধিক সন্তান একসাথে বেছে লিংক করা যাবে
- **তদারকি/ফলোআপ নোট**: টিউটর প্রতি স্টুডেন্টের জন্য টাইমস্ট্যাম্পড নোট লিখে রাখতে পারবেন; অভিভাবক সেটা পড়তে পারবেন
- **পেমেন্ট/স্যালারি স্লিপ**: টিউটর মাসভিত্তিক পেমেন্ট রিসিভ মার্ক করলে অভিভাবকের কাছে স্বয়ংক্রিয়ভাবে নোটিফিকেশন/স্লিপ যাবে; এডমিন সব টিউটরের সম্মিলিত আদায় দেখতে পারবেন
- **পুশ নোটিফিকেশন**: টপবারে 🔔 আইকনে চেপে চালু করলে, অ্যাপ ব্যাকগ্রাউন্ডে/মিনিমাইজড থাকলেও সিস্টেম নোটিফিকেশন পাবেন। ⚠️ সীমাবদ্ধতা: এটা ব্রাউজার/অ্যাপ পুরোপুরি বন্ধ থাকলে কাজ করবে না (সেজন্য Firebase Cloud Functions লাগে, যেটার জন্য Blaze প্ল্যান/কার্ড দরকার) — এই ফ্রি ভার্সনটা অ্যাপ চালু/ব্যাকগ্রাউন্ডে থাকা অবস্থাতেই কাজ করে। আইফোনে Safari-তে কাজ করতে হলে অ্যাপটা হোম-স্ক্রিনে ইনস্টল করা থাকতে হবে (Apple-এর নিয়ম)।
- **ছবি/ফাইল অ্যাটাচমেন্ট**: স্টুডেন্ট পড়া "সম্পন্ন" মার্ক করার সময় হোমওয়ার্কের ছবি তুলে/আপলোড করে জমা দিতে পারবে। ছবি স্বয়ংক্রিয়ভাবে ছোট (কম্প্রেস) করে রাখা হয়, যাতে **Firebase-এর ফ্রি Spark প্ল্যানেই** (কোনো কার্ড ছাড়াই) কাজ চলে — Firebase Storage ব্যবহার করা হয়নি ইচ্ছাকৃতভাবে, কারণ সেটা এখন Blaze প্ল্যান (কার্ড) ছাড়া পাওয়া যায় না। এর বদলে প্রতিটা ছবি আলাদাভাবে Firestore-এ (একটা করে ছোট ডকুমেন্ট হিসেবে) রাখা হয়।

## Firebase ফ্রি প্ল্যান সম্পর্কে জেনে রাখা ভালো
- Firestore (এই অ্যাপের মূল ডাটাবেস) সম্পূর্ণ ফ্রি Spark প্ল্যানে থাকে, কোনো কার্ড লাগে না — এই অ্যাপের স্কেলে (কয়েকজন ইউজার) কখনো ফ্রি সীমা ছাড়াবে না।
- Firebase Storage (বড়/আসল ছবি রাখার সার্ভিস) ফেব্রুয়ারি ২০২৬ থেকে Blaze প্ল্যান (কার্ড) ছাড়া পাওয়া যায় না — তাই এই অ্যাপ ইচ্ছাকৃতভাবে সেটা এড়িয়ে ছবি কম্প্রেস করে Firestore-এ রাখে।
- Cloud Functions (সত্যিকার সার্ভার-পুশ নোটিফিকেশনের জন্য দরকার) সবসময়ই Blaze প্ল্যান লাগে।
- ভবিষ্যতে চাইলে Blaze-এ আপগ্রেড করা যাবে (এই স্কেলে বিল সম্ভবত ৳০-ই থাকবে, Google-এর "Always Free" কোটার মধ্যে) — তখন বড় ছবি/ভিডিও ও সত্যিকার সার্ভার-পুশ যোগ করা সহজ হবে।
